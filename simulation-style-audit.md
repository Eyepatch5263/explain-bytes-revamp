# Simulation Style Audit

The reader routes already provide a consistent Flash Docs shell, but the imported DNS, database, and load-balancing modules retain standalone white-card, rounded-corner, utility-typography, and generic gray-control treatments. The simulation route will receive a shared `flashdocs-simulation-shell` theme layer that standardizes panel surfaces, controls, tables, fields, borders, grid canvases, active states, and accent colors while preserving the existing interactive component logic.
